# ☕️ Coffee Quality Prediction

This project predicts coffee quality scores (`Total.Cup.Points`) using machine learning regression models.

## 💡 Summary
- Dataset: Cleaned coffee data (Arabica & Robusta)
- Target: `Total.Cup.Points`
- Models: Linear Regression, RidgeCV, Random Forest
- Preprocessing: Missing value handling, encoding, scaling, train/test split
- Metrics: MAE, RMSE, R²

📁 Includes code, results, and visualizations.  
📂 See `coffee_quality_ML.ipynb` for full workflow.

Course: CS435 – ML (2025)
